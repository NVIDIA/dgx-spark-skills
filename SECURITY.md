# Security Policy

Please do not disclose potential vulnerabilities in public issues or pull requests.

Report security vulnerabilities or AI security concerns through
[NVIDIA's Vulnerability Disclosure Program](https://www.nvidia.com/en-us/security/report-vulnerability/)
or email [NVIDIA PSIRT](mailto:psirt@nvidia.com). For email reports, encrypt
sensitive information using [NVIDIA's public PGP key](https://www.nvidia.com/en-us/security/pgp-key/).

Include the affected skill and version or commit, a description of the issue,
steps to reproduce it, any proof of concept, and its potential impact.
