# DGX Spark Skills

A portable NVIDIA-authored agent skill for DGX Spark and related GB10 systems,
with guidance for system identification, troubleshooting, updates, playbooks,
NVIDIA Sync, diagnostics, and support preparation.

The collection lives in [skills/dgx-spark-skills](skills/dgx-spark-skills/).
